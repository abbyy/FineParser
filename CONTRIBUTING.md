# Contributing

Thanks for wanting to help improve FineParser.

## What this repository is

FineParser is a **commercial ABBYY product** distributed as a Docker image. Its source code is not public and does not live here.

This repository holds FineParser's documentation entry point and serves as its **community support channel**. That shapes what contribution means here: there is no codebase to send pull requests against, but the things below genuinely improve the product.

> The `LICENSE` file covers the contents of *this repository* — the documentation and templates. The FineParser Docker image is licensed separately, under the terms you accept when you sign up for a plan.

## What helps most

### Good bug reports

The highest-value contribution. A report that includes the image tag, the exact command, the recognition settings, and the actual error gets fixed; one that says "it doesn't work" usually cannot be. [SUPPORT.md](./SUPPORT.md) lists exactly what to include, and the [bug report form](https://github.com/abbyy/FineParser/issues/new?template=bug_report.yml) asks for each item.

Search [existing issues](https://github.com/abbyy/FineParser/issues) first — if someone has already reported it, adding your environment details and reproduction to that thread is more useful than a new issue.

### Feature requests

Tell us the problem before the solution. What are you trying to do, what does your current workaround cost you, and what would good look like? Use the [feature request form](https://github.com/abbyy/FineParser/issues/new?template=feature_request.yml).

### Documentation corrections

If a page at [docs.abbyy.com/fine-parser](https://docs.abbyy.com/fine-parser/getting-started/introduction) is wrong, outdated, confusing, or incomplete, tell us. Open an issue here with the page URL and what is wrong with it. Commands that don't work as documented are especially worth reporting — they cost every reader who tries them.

### Answering other people's questions

If you have run into something before and see someone else hit it, say so. Community answers are often faster and more practical than ours.

### Improvements to this repository

The files here — `README.md`, `AGENTS.md`, `SUPPORT.md`, the issue templates — *do* accept pull requests. Corrections to commands, clarifications, broken links, and improvements to the agent runbook are all welcome. Please open an issue first for anything substantial, so we can agree on the shape before you spend time on it.

## Ground rules

- **Never post API keys, license GUIDs, or confidential documents** in an issue or pull request. Redact before you submit.
- Be civil. This repository follows the [Code of Conduct](./CODE_OF_CONDUCT.md).
- Keep billing and account questions out of public issues — those go through the channels in [SUPPORT.md](./SUPPORT.md).

## Response expectations

Community support is best-effort. ABBYY monitors this repository, but Free, Starter, Growth, and Business plans all carry no contractual response time. Enterprise adds SLAs and ABBYY technical support. See [SUPPORT.md](./SUPPORT.md).
